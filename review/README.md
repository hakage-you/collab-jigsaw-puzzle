# レビュー用の画像

ゲームはこのフォルダーを読み込みません。人が見た目を確かめるための画像だけを置きます（公開用ファイルを作るようになったら、このフォルダーごと公開範囲から外す）。

## effects/<デザイン方針>/

`tests/effects/effects.test.js` が書き出し、テストのたびに今の描画と比べます。

- `stamps/<形>-<色>.png`: 部品 1 つ。上がライト、下がダーク。左から原寸（64 px）、32・16・11 px。
- `sheet.png`: すべての部品を並べた一覧。新しい部品がほかから浮いていないかを見る。
- `strips/<エフェクト>.png`: 動きを 1 コマずつ横に並べた帯（2 倍に拡大）。

## エフェクトを足す・変えるとき

1. 今ある部品（`src/render/effects/shapes.js`）の組み合わせで作れないかを先に確かめる。
2. 作れなければ、形だけを足す（縁・影・色はデザイン方針が付ける）。色は `styles/tokens.css` の `--fx-*` と `effectRecipes.js` の色の役割で足す。
3. `src/render/effects/effectRecipes.js` にエフェクトを名前だけで書く。
4. `npx vitest run tests/effects -u` で画像を更新し、`sheet.png` と `strips/` を見て、コミットの差分で前後を見比べる。

検査は 2 つに分かれています。

- `tests/effects/invariants.js`: どの方針でも変わらない決まり（明滅、数と長さの上限、強さの設定、フレームレート、盤面で埋もれないこと）
- `tests/effects/<方針>.checks.js`: その方針だけの決まり（紙なら、白い縁が一周、右下の影、コマ送り）
