    利用規約・免責事項・プライバシー

    1. 免責事項・無保証の原則

    本アプリケーションは現状有姿（AS-IS）で提供されます。動作の完全性、P2P 通信の安定性、外部 API の応答、API クォータ消費等について開発者は一切の保証を行わず、利用者の自己責任においてご利用いただくものとします。

    2. データ非収集・サーバー非保存

    開発者側のサーバーへパズル画像、セーブデータ、YouTube API キー、配信コメント等を送信・収集・保存することは一切ありません。すべての設定と作業状態は利用者自身のブラウザ内でのみ処理されます。

    3. P2P マルチプレイ時の通信リスク

    マルチプレイでは WebRTC の仕組み上、接続元 IP アドレスやパズル画像データが参加者間で共有されます。信頼できる相手とのみ招待 URL を共有してください。

    4. YouTube Data API v3 の利用

    コメント連動にはホスト自身が Google Cloud Console で発行した API キーを使用します。公開・限定公開ライブチャットの読み取り専用アクセスのみを行い、Google API 利用規約および YouTube 利用規約に従ってご利用ください。

    YouTube API キーの取得・設定ガイド

    1. ホストご自身の API キーを使用する理由

    安全性と最小限の権限（配信チャットの読み取り専用）を保ちつつ安定してコメント連動を行うため、少しお手数をおかけしますがホストご自身の Google API キーをご利用いただく方式を採用しています。

    入力した API キーはご利用中のブラウザのメモリ上のみに保持され、リロードやタブを閉じると自動で消去されます（セーブ JSON や P2P 通信にも含まれません）。

    2. 初回作成手順（Google Cloud Console）

    1. Google Cloud Console でプロジェクトを作成し、「YouTube Data API v3」を有効化します。
    2. 「API とサービス」→「認証情報」から新しい API キーを作成します。
    3. 作成したキーの編集画面で「API の制限」→「キーを制限」を選び、YouTube Data API v3 のみ を選択して保存してください。

    3. ご利用時の注意

    公開・限定公開のライブ配信チャットに対応しています（メンバー限定チャット・配信開始前・アーカイブではチャットを取得できません）。1日の無料枠は 10,000 ユニット（10秒間隔で約5.5時間目安）です。
