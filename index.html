    利用規約・免責事項・プライバシー

    1. 免責事項・無保証の原則

    本アプリケーションは現状有姿（AS-IS）で提供されます。動作の完全性、P2P 通信の安定性、外部 API の応答、API クォータ消費等について開発者は一切の保証を行わず、利用者の自己責任においてご利用いただくものとします。

    2. データ非収集・サーバー非保存

    開発者側のサーバーへパズル画像、セーブデータ、YouTube API キー、配信コメント等を送信・収集・保存することは一切ありません。すべての設定と作業状態は利用者自身のブラウザ内でのみ処理されます。

    3. P2P マルチプレイ時の通信リスク

    マルチプレイでは WebRTC の仕組み上、接続元 IP アドレスやパズル画像データが参加者間で共有されます。信頼できる相手とのみ招待 URL を共有してください。

    4. YouTube Data API v3 の利用

    コメント連動にはホスト自身が Google Cloud Console で発行した API キーを使用します。公開・限定公開ライブチャットの読み取り専用アクセスのみを行い、Google API 利用規約および YouTube 利用規約に従ってご利用ください。

    YouTube APIキーの取得・設定ガイド

    1. なぜご自身のAPIキーが必要なの？（無料運営の仕組み）

    少し見慣れない操作でお手数をおかけしますが、本アプリをサーバーレスかつ無料で運営し続けるために、ホストご自身のYouTube APIキーをご利用いただく方式を採用しています。

    開発者側の共有キーを使う方式では、多くの配信が重なるとすぐに1日の利用上限に達したり、高額な維持費が発生したりしてしまいます。また、Googleアカウントでログイン連携（OAuth）する方式と比べ、アカウント操作の権限を渡さずに済む安全な仕組みでもあります。

    2. どんな権限を渡すの？（できること・できないこと）

    下記の手順どおりに「YouTube Data API v3 のみ」に制限したAPIキーを作成した場合、許可される範囲は次のとおりです。

    • できること: 公開・限定公開されている配信の基本情報と、ライブチャットの読み取りのみ
    • できないこと: 動画の投稿・削除、チャンネル設定の変更、チャットの代理送信、非公開動画やメンバー限定チャットの閲覧、GmailやGoogleドライブなど他のGoogleサービスへのアクセス

    ※2026年11月21日時点の YouTube Data API v3 仕様および動作確認に基づく内容です。

    3. このゲームでは何に使うの？（データの扱いと保存オプション）

    入力されたAPIキーは、あなたのブラウザからGoogleの公式APIへ直接問い合わせるためだけに使います。行う通信は次の読み取り（GET）のみです。

    1. 配信URLまたは動画IDから、ライブチャットを特定する（接続確認時に1回）
    2. 配信中のコメントやスパチャを一定間隔で読み取り、お邪魔や演出に使う

    キーの保存と保護について

    • 初期設定（推奨）: ブラウザのメモリ上のみで扱い、リロードやタブを閉じると自動で消去されます。
    • ブラウザに保存（任意オプション）: 次回からの再入力を省きたい場合は、リスクを確認・承諾したうえで設定画面のスイッチからブラウザ内（localStorage）へ保存できます。いつでもスイッチをオフにするか「消去」ボタンで削除できます。
    • 保存時の注意: ブラウザ（localStorage）に保存したキーは、手動でオフまたは消去するまで期限なく残ります。また、共有PCの別ユーザーやブラウザ拡張機能などから読み取られるリスクがあります。共有PCでは使わず、必ず「YouTube Data API v3 のみ」に制限したキーをご使用ください。
    • 外部送信なし: どちらの設定でも、開発者サーバーへの送信・セーブファイルへの保存・参加者（P2P）への共有は一切行いません。

    4. 料金はかかる？（無料枠と配信時間の目安）

    YouTube Data API v3 には1日あたり10,000ユニットの無料枠があります。Google Cloud で課金設定（請求先アカウントの登録）を行わない限り、自動的に料金が発生することはありません。

    • 取得間隔 5秒: 約2.7時間／日
    • 取得間隔 10秒（標準）: 約5.5時間／日
    • 取得間隔 15秒（節約）: 約8.3時間／日

    上限に達した場合はその日のコメント取得が止まりますが、翌日に無料枠が自動でリセットされます。

    5. 取得・設定手順（初回のみ）

    1. Google Cloud Console にGoogleアカウントでログインし、新しいプロジェクトを作成します（プロジェクト名は何でも構いません）。
    2. 左メニューの「APIとサービス」→「ライブラリ」から「YouTube Data API v3」を検索し、「有効にする」をクリックします。
    3. 「APIとサービス」→「認証情報」を開き、上部の「認証情報を作成」→「APIキー」を選びます。
    4. 作成されたAPIキーの編集画面を開き、「APIの制限」で「キーを制限」を選択し、一覧から「YouTube Data API v3」のみにチェックを入れて保存します。
    5. 発行されたキー（AIza... から始まる文字列）をコピーし、この画面の「YouTube APIキー」欄に貼り付けて完了です。

    ※手順内のメニュー名称は2026年11月21日時点の Google Cloud Console の表示に基づきます。Google側のアップデートにより表記が変わる場合があります。

    6. 配信時の注意点（漏洩対策・対応条件）

    • 配信画面にキーを映さない: 入力欄は伏せ字になりますが、Google Cloud Console の画面やコピー操作をOBS等の配信画面に映さないようご注意ください。
    • 万が一映ってしまったら: Google Cloud Console の「認証情報」から該当のAPIキーを削除し、新しく作り直せばすぐに無効化できます。
    • 対応する配信: 公開・限定公開の配信中ライブチャットに対応しています（配信開始前・アーカイブ・メンバー限定チャットは取得できません）。
    うまく接続できないときは（よくある原因）
    • チャットが見つからない: 配信が開始されているか、YouTube側の設定でライブチャットが有効になっているかをご確認ください。
    • 権限エラー（403）が出る: 「YouTube Data API v3」の有効化忘れ、またはキーの制限設定が保存されていない可能性があります。
    • 上限エラー（クォータ超過）が出る: 1日の無料枠を使い切っています。取得間隔を15秒に延ばすか、翌日のリセットをお待ちください。
