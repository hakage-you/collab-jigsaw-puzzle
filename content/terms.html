1. 免責事項・無保証の原則

本アプリケーションは現状有姿（AS-IS）で提供されます。動作の完全性、P2P通信の安定性、外部APIの応答、APIクォータ消費等について開発者は一切の保証を行わず、利用者の自己責任においてご利用いただくものとします。

2. データ非収集・サーバー非保存

開発者側のサーバーへパズル画像、セーブデータ、YouTube APIキー、配信コメント等を送信・収集・保存することは一切ありません。すべての設定と作業状態は利用者自身のブラウザ内でのみ処理されます。

3. P2Pマルチプレイ時の通信とリスク

マルチプレイでは、PeerJSという仕組みを使って接続相手を見つけるため、部屋IDを公開の仲介サーバーに送信します。接続後のパズル画像・セーブデータ・操作内容などは仲介サーバーを通らず、ブラウザ同士で直接通信（P2P）されます。

WebRTCの仕組み上、同じ部屋の参加者間では接続元IPアドレスやパズル画像データが共有されます。信頼できる相手とのみ招待URLを共有してください。

4. YouTube Data API v3の利用

コメント連動にはホスト自身が Google Cloud Console で発行したAPIキーを使用します。公開・限定公開ライブチャットの読み取り専用アクセスのみを行い、Google API利用規約およびYouTube利用規約に従ってご利用ください。
